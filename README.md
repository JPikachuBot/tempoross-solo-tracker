# Tempoross Solo Tracker (RuneLite)

Interactive sidebar checklist for solo Tempoross runs.

## Features
- Phase-based checklist with optional recovery phase
- Active-step highlighting
- State persistence between sessions
- Auto-reset when entering the Tempoross fight region
- Storm intensity warning (92%+) during the cook warning steps

## Development / running locally
```bash
./gradlew clean run
```

## Notes
This plugin is intended for submission to the RuneLite Plugin Hub.
