# Tempoross Solo Tracker (RuneLite)

Interactive sidebar checklist + storm intensity notifier for **solo Tempoross** runs.

## Features
- Phase checklist (Phases 1–4 + optional Recovery)
- Active-step highlighting (highlights the step after the lowest checked box)
- Storm intensity notification (user-defined threshold; notifies on rising edge, like Idle Notifier)
- Solo-only gating: storm tracking starts only after clicking **Solo-start** on the Tempoross boat
- Auto-reset when returning to the Tempoross lobby region (12588)

## Notes
Intended for submission to the RuneLite Plugin Hub.
